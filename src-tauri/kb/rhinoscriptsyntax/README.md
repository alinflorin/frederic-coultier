# rhinoscriptsyntax reference

The functions of `rhinoscriptsyntax` (imported as `rs`), the library a design script uses in Rhino. Written for IronPython 2.7: no f-strings, `print("x")` with one argument. One file per module; search with `kb search`, read with `kb cat rhinoscriptsyntax/curve.md`. Each entry has the signature, the arguments, what it returns and an example.
